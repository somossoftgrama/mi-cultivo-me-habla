# My Crop Speaks to Me

**Built for the Meta Global AI Developer Hackathon 2026** — Track: Indie Developer

A plant care assistant that gives voice to your crops. Send a photo of your plant and receive a voice note from the plant itself, in first person, telling you what it needs.

## Problem

Small farmers have a camera in their pocket but no agronomist nearby. Generic apps give a label on a single photo, with no follow-up or in their language. My Crop Speaks to Me lets the crop speak for itself.

## How It Works

1. Farmer sends a photo of their crop (via web app)
2. Muse Spark (agent brain) analyzes the image and responds as the plant
3. ElevenLabs TTS converts the response into a voice note
4. The voice note is played back to the farmer

## Setup

```bash
# Clone the repo
git clone <repo-url>
cd mi-cultivo-me-habla

# Create virtual environment
python3 -m venv .venv
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Configure environment
cp .env.example .env
# Edit .env with your API keys:
#   META_API_KEY=your_meta_api_key
#   ELEVENLABS_API_KEY=your_elevenlabs_api_key

# Run the server
uvicorn src.main:app --reload --host 0.0.0.0 --port 8000
```

Open http://localhost:8000 in your browser.

## Design Principles

1. **No new app needed**: lives in web (WhatsApp in future phase)
2. **The object is the interface**: no menus, you talk to your plant
3. **Built for non-tech users**: if it works for a farmer, it works for everyone
4. **With memory**: each photo is compared with previous ones
5. **Takes initiative**: the crop writes first when risk rises (frost, rain forecast)
